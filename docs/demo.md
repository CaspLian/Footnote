# Resettable two-minute demo

Use the native development client and bundled fictional Northline documents. On a fresh install, complete language, personal context, coverage and explanation preferences. App labels remain English. Settings → Reset the sample preserves household profiles and imported cases.

| Time | Action | Explain |
| --- | --- | --- |
| 0:00–0:20 | Show Home camera and Add documents. Select two synthetic PDFs or photos, then preview the confirmation screen. | A bill, an EOB, or both are accepted. More camera captures can be added. Understanding starts only after Use document(s); the connected backend will own the duration. Current arbitrary imports offer manual entry. |
| 0:20–0:45 | Open the bundled sample, confirm details, open review and a source-linked question. | $494 statement balance, $294 EOB responsibility, $50 prior payment and $244 derived remainder remain distinct. The $250 difference is a question, not guaranteed savings. |
| 0:45–1:00 | Spin/tap the orb; show Talk it through and voice chooser; tuck away/restore it. | This is a future contextual live-agent conversation. The prototype shows unavailable recovery; it does not pretend TTS is a conversation. |
| 1:00–1:25 | Prepare a billing correction, edit a sentence, copy or export PDF. | Drafts save locally. Insurer appeal is a separate template requiring a real reason/decision. Export does not submit. |
| 1:25–1:45 | Explicitly mark the fictional request submitted. Open Timeline, select a native follow-up date and Save reminder. | The app records a local action; it did not send anything. Follow-up is not a legal deadline or a scheduled notification. |
| 1:45–2:00 | Return Home/Bills, show status and retained draft; show reset control. | Family and case context stay on this device. |

Outside the timed demo: cancel a picker, deny camera permission, preview corrupt/encrypted PDFs, confirm a single EOB with missing financial fields, retry a failed understanding adapter, recover a draft and repeat submission. `mobile/assets/fixtures/qa/password-protected.pdf` uses `unfold-qa`; preview passwords stay in memory. Genuine live service, camera permission, native keyboard/drag performance and Android runtime checks remain separate from this demo script.
