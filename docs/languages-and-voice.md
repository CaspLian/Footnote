# Working languages and live voice

Unfold saves 32 working-language choices in `mobile/src/domain/languages.ts`. They cover English, Spanish, French, German, Italian, Portuguese (Brazil/Portugal), Chinese (Simplified/Traditional), Japanese, Korean, Hindi, Arabic, Hebrew, Dutch, Swedish, Danish, Finnish, Norwegian, Polish, Czech, Slovak, Hungarian, Romanian, Greek, Russian, Ukrainian, Turkish, Indonesian, Malay, Thai and Vietnamese. Regional Portuguese/Chinese choices map to `pt`/`zh` at the agent boundary. The app interface remains English; choosing a working language does not claim translated app labels or a connected translated document service.

The [ElevenAgents language guidance](https://elevenlabs.io/docs/help-center/product/eleven-agents/which-languages-can-i-use-with-eleven-agents) ties language coverage to the configured speech model. The [multilingual configuration reference](https://elevenlabs.io/docs/eleven-agents/customization/voice/customization/language) supports per-session language overrides; Unfold ends an active session when the working language changes. [Model language lists](https://elevenlabs.io/docs/help-center/other/what-languages-do-you-support) vary: Hebrew and Thai require a compatible model such as Eleven v3, rather than assuming Flash v2.5 supports every option. The backend must validate its model/language/voice combination and return a recoverable unavailable state. The [Creator Agents plan](https://elevenlabs.io/pricing/agents?price.platform=agents_platform) inherits multilingual support; this catalog is not a promise that every voice/model combination is included or already connected. Sources reviewed October 10, 2026.

The choices align with [Apple's localization guidance](https://developer.apple.com/localization/) and [App Store localization catalog](https://developer.apple.com/help/app-store-connect/reference/app-information/app-store-localizations/). Actual per-app UI language switching requires complete localized resources; those translations are outside this English-first iteration.

Flags were bundled from [FlagCDN](https://flagcdn.com) at 80px width into `mobile/assets/flags` and work offline. They are secondary cues for representative locales, alongside explicit language and native-language names; no language is treated as belonging exclusively to one country. The requested Figma flag library was accessible and its editable US/ES/IN vectors were inspected in the prototype. iOS selection uses a native navigation search bar in a form sheet; web and Android use accessible themed controls.

Calm/Clear/Warm are preference placeholders. Voice samples require `configureVoicePreviewAdapter`; live conversations require `configureAgentAdapter`. Neither silently plays a system voice. Settings displays the orb icon, while the chooser uses a large spinable orb, paged voices, preview/stop, working language and a full-width confirmation action. No microphone or medical data leaves the device in the default build.
